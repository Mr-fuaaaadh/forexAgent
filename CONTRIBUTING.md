# Contributing

1. Read `AGENTS.md` and the relevant specification documents.
2. Open an issue for behavioral changes or ambiguous requirements.
3. Keep changes small and focused; do not weaken risk controls.
4. Add deterministic tests or a reproducible manual test plan.
5. Update documentation and `CHANGELOG.md`.
6. Report the exact checks run. Never state that MetaEditor compilation or Strategy Tester validation passed unless it actually did.

## Pull requests
Include purpose, design, safety impact, test evidence, broker/account assumptions, and known limitations. Trading behavior changes require explicit review of strategy and risk documents.
